# Котята-пираты — интерактивная обучающая книга (Godot 4)

Цифровой аналог детской книги-нажималки: 12 тематических экранов,
тап-задания с текстовыми облачками (звук подключается позже).

## Запуск

Вариант 1 — редактор:
1. Открой Godot 4.x → Import → выбери папку `godot/`
2. F5 — запуск

Вариант 2 — из терминала:
```bash
cd godot
godot          # редактор
godot .        # сразу игра
```

## Структура

```
project.godot            — настройки (1280×720, landscape, touch)
data/screens.json        — ВСЁ содержание: 12 экранов, предметы, задания
scenes/Main.tscn         — главное меню (список экранов)
scenes/ScreenCard.tscn   — карточка экрана (заголовок + задание + предметы)
scripts/Main.gd          — меню
scripts/ScreenCard.gd    — карточка + движок заданий
tools/validate_data.gd   — проверка данных
```

## Как добавить/изменить экран

Код не трогаем — правим только `data/screens.json`:

```json
{
  "id": "13_new", "num": 13,
  "title": "Название", "topic": "Подтема",
  "bg_color": "#aabbcc", "sticker_color": "#112233",
  "items": [
    {"id": "item1", "label": "Предмет", "color": "#ff0000", "tags": ["big"]}
  ],
  "tasks": [
    {"type": "tap",   "text": "Покажи большое!",  "target_tags": ["big"], "hint": "Подсказка"},
    {"type": "tap",   "text": "Где предмет?",     "target_id": "item1"},
    {"type": "count", "text": "Посчитай...",      "target_tags": ["coins"]},
    {"type": "dial",  "text": "Позвони другу!",   "contact": 3}
  ]
}
```

Экран `06_radio` дополнительно содержит `"contacts": [{"num", "label"}]` —
для него рисуется клавиатура цифр вместо предметов.

## Типы заданий

| Тип | Механика |
|---|---|
| `tap` | «Покажи X» — цель по `target_tags` или конкретный `target_id` |
| `count` | Тапнуть все предметы группы, счёт отображается |
| `dial` | Набрать номер героя на клавиатуре рации |

После 2 промахов правильные кнопки начинают пульсировать, появляется
подсказка Пушка. Проигрышей нет.

## Проверка данных

```bash
cd godot && godot --headless -s tools/validate_data.gd
```
